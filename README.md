## Σκοπός

Το ΣΑΠ-ΦΘ αποτελεί ένα ολοκληρωμένο σύστημα συλλογής, ανάλυσης και απεικόνισης δεικτών ποιότητας που αφορούν την πρακτική άσκηση φοιτητών Φυσικοθεραπείας.

Το σύστημα βασίζεται σε:

- Google Forms
- Google Sheets
- Microsoft Excel
- Python
- Google Apps Script
- Looker Studio
