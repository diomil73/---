# ΣΑΠ-ΦΘ

## Σύστημα Αξιολόγησης και Ποιότητας Πρακτικής Άσκησης Φυσικοθεραπείας

Το ΣΑΠ-ΦΘ είναι ένα σύστημα επεξεργασίας δεδομένων αξιολόγησης
της πρακτικής άσκησης φοιτητών Φυσικοθεραπείας.

Το πρόγραμμα:

- εισάγει δεδομένα από αρχείο Excel
- μετατρέπει τις απαντήσεις Likert σε αριθμητικές βαθμολογίες
- υπολογίζει μέσους όρους ανά ερώτηση και ενότητα
- υπολογίζει τον συνολικό δείκτη IQI
- αναλύει τις ανοιχτές απαντήσεις
- εντοπίζει ισχυρά σημεία και προτεραιότητες βελτίωσης
- δημιουργεί τελικές αναφορές Excel

---

## Απαραίτητα αρχεία

Το αρχείο δεδομένων πρέπει να βρίσκεται στη θέση:

```text
data/google_forms_export.xlsx
---
Το όνομα του αρχείου πρέπει να παραμένει ακριβώς:
google_forms_export.xlsx

Δημιουργία όλων των αναφορών

Πριν από την εκτέλεση:

Κλείστε όλα τα αρχεία Excel που δημιουργούνται από το πρόγραμμα.
Τοποθετήστε το νέο αρχείο δεδομένων στον φάκελο data.
Ενεργοποιήστε το Python virtual environment.

Στο PowerShell εκτελέστε:
.\venv\Scripts\Activate.ps1
Στη συνέχεια εκτελέστε:
python .\python\run_all.py


Παραγόμενα αρχεία

Τα αποτελέσματα αποθηκεύονται στον φάκελο:

excel

Δημιουργούνται τα παρακάτω αρχεία:

1. ΣΑΠ-ΦΘ_MASTER.xlsx

Περιλαμβάνει:

Dashboard
μέσους όρους ανά ενότητα
αρχικά δεδομένα
αριθμητικά δεδομένα
metadata ερωτήσεων
2. QUESTION_ANALYTICS.xlsx

Περιλαμβάνει:

στατιστικά ανά ερώτηση
σύνοψη ανά ενότητα
ισχυρότερα σημεία
προτεραιότητες βελτίωσης
3. TEXT_ANALYTICS.xlsx

Περιλαμβάνει:

σύνοψη ανοιχτών ερωτήσεων
όλες τις ανοιχτές απαντήσεις
συχνές λέξεις ανά ερώτηση
συνολικές συχνές λέξεις
4. ΣΑΠ-ΦΘ_FINAL_REPORT.xlsx

Περιλαμβάνει:

διοικητική σύνοψη
συνολικό δείκτη IQI
αποτελέσματα ανά ενότητα
αποτελέσματα ανά ερώτηση
ισχυρά σημεία
προτεραιότητες βελτίωσης
ανάλυση ανοιχτών απαντήσεων
Κλίμακα βαθμολόγησης

Οι απαντήσεις Likert μετατρέπονται σε αριθμητική κλίμακα:

Βαθμολογία	Ερμηνεία
5	Πολύ θετική απάντηση
4	Θετική απάντηση
3	Ουδέτερη απάντηση
2	Αρνητική απάντηση
1	Πολύ αρνητική απάντηση

Απαντήσεις όπως:

Δεν συμμετείχα
Δεν εφαρμόζεται
Δεν γνωρίζω

δεν λαμβάνουν αριθμητική βαθμολογία και δεν συμμετέχουν στον
υπολογισμό των μέσων όρων.

Στα αριθμητικά φύλλα εμφανίζονται ως κενά κελιά.
